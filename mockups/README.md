# Design mockups

Local copies of the design canvases, so the mockups survive outside claude.ai.
Each `project/` folder holds the canvas index (`canvas.json`) and one `.dc.html` per artboard.

| Folder | Canvas | What it covers |
| --- | --- | --- |
| `table-redesign/` | https://claude.ai/artifact/6d3HDJv3N4KGpJhn5Sqjkq | Table-first game screen: betting, your turn, payouts, bankrupt dealer, game over, 9–10 players |
| `home-redesign/` | https://claude.ai/artifact/RQErQsbCr68UfeQ3ecjVpB | Home page: name once, then Create a lobby (friends or vs computer) or Join a lobby; desktop and phone |

The table canvas's "Screenshots from real games" artboard points at images uploaded to that canvas,
so those images only show on claude.ai.
